# RFC 9728 (OAuth 2.0 Protected Resource Metadata), excerpts

§3.1: The well-known URI is formed by inserting "/.well-known/oauth-protected-resource"
between the host and the path of the resource identifier (if any).

§5.1: A protected resource MAY include a "resource_metadata" parameter in the
WWW-Authenticate challenge. When it is present, the client MUST use the
metadata URL from the challenge and MUST NOT fall back to constructing
well-known URLs for this resource.
